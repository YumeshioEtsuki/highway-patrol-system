## 🔧 后端API适配

### 已修复的接口匹配问题

#### 创建巡查记录接口
**后端期望** (`POST /api/patrol`):
```
FormData:
  segment_id: int (路段ID)
  issue_type_id: int (问题类型ID)
  description: string (描述)
  severity: int (严重度)
  latitude: float
  longitude: float
  photo: File[] (照片文件)
```

**小程序实现**:
```javascript
uploadPatrolRecord({
  segment_id: 1,
  issue_type_id: getProblemTypeId(problem_type),
  description: `${location_desc} - ${problem_desc}`,
  severity: severity,
  latitude: latitude,
  longitude: longitude
}, photos[])
```

#### 管理员接口路径
- 列表: `GET /api/admin/patrol/list` (参数: status_filter)
- 统计: `GET /api/admin/stats`
- 完成: `POST /api/patrol/{id}/complete` (body: {remark})

## 🚀 部署指南

### 本地测试
1. 启动后端服务器
   ```bash
   cd 1-后端代码
   python start_server.py
   ```

2. 配置小程序baseUrl
   ```javascript
   // app.js
   globalData: {
     baseUrl: 'http://127.0.0.1:5000'
   }
   ```

3. 微信开发者工具导入项目

### 真机测试
1. 确保手机和电脑在同一WiFi
2. 修改baseUrl为电脑IP
   ```javascript
   baseUrl: 'http://192.168.x.x:5000'
   ```
3. 扫码预览

### 生产部署
1. 后端部署到服务器
2. 配置HTTPS域名
3. 小程序后台配置服务器域名
4. 修改baseUrl为生产域名
5. 上传代码审核

### 调试方法
1. **查看Console日志**
   - 微信开发者工具 → Console面板

### 常见错误
- **401**: Token失效 → 重新登录
- **404**: 接口路径错误 → 检查baseUrl
- **422**: 参数错误 → 检查字段格式
- **500**: 后端错误 → 查看后端日志
