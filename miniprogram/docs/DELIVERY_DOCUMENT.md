## 📱 部署配置

### 1. 开发环境配置

**app.js 配置**：
```javascript
globalData: {
  baseUrl: 'http://127.0.0.1:5000',  // 本地开发
  // baseUrl: 'http://你的服务器IP:5000',  // 生产环境
}
```

### 2. 真机测试配置

**步骤**：
1. 查看电脑IP：`ipconfig`（Windows）或 `ifconfig`（Mac/Linux）
2. 修改app.js中的baseUrl为局域网IP
3. 确保后端监听0.0.0.0：
   ```python
   app.run(host='0.0.0.0', port=5000)
   ```
4. 放行防火墙5000端口
5. 微信开发者工具点击"预览"
6. 手机扫码测试

### 3. 生产环境配置

**需要准备**：
- 已备案的域名
- HTTPS证书（SSL）
- 服务器公网IP
- 微信小程序AppID

**配置步骤**：
1. 在微信公众平台配置服务器域名（request、uploadFile、downloadFile）
2. 修改app.js中baseUrl为生产域名
3. 后端部署到服务器并启用HTTPS
4. 在开发者工具中上传代码
5. 提交审核
6. 审核通过后发布

## 📝 使用说明

### 巡查员使用流程

1. **登录**：选择"巡查员"角色，点击"微信一键登录"
2. **查看列表**：首页查看所有巡查记录
3. **创建记录**：
   - 点击右下角"+"按钮
   - 等待GPS自动定位
   - 填写位置描述和问题描述
   - 选择问题类型和严重程度
   - 拍摄或上传现场照片
   - 点击"提交记录"
4. **查看详情**：点击列表中的记录卡片查看详细信息
5. **筛选记录**：使用顶部筛选栏按状态筛选

### 管理员使用流程

1. **登录**：选择"管理员"角色登录
2. **查看待审核列表**：首页显示所有待处理记录
3. **审核记录**：
   - 点击记录进入详情
   - 查看问题信息和现场照片
   - 在地图中查看位置
   - 填写处理备注
   - 点击"标记处理中"或"标记已完成"
4. **筛选记录**：按状态筛选不同阶段的记录

## 🐛 已知问题与限制

### 技术限制
1. **GPS定位**：室内信号弱，建议在室外使用
2. **照片上传**：大图上传较慢，已自动压缩优化
3. **网络依赖**：需要稳定的网络连接

### 使用建议
1. 创建记录时确保GPS定位成功
2. 上传照片时建议使用WiFi
3. 真机测试需配置局域网IP
4. 定期清除缓存以保持最佳性能
