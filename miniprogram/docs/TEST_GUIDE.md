# 小程序测试指南

## 📱 测试环境准备

### 1. 微信开发者工具设置
1. 打开微信开发者工具
2. 导入项目：选择 `2-小程序代码` 目录
3. AppID：使用测试号（点击右上角切换到测试号）
4. 关闭域名校验：
   - 右上角 `详情` → 本地设置
   - 勾选 `不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书`

### 2. 后端服务启动
```bash
cd 1-后端代码
python start_server.py
```

后端服务运行在：http://127.0.0.1:5000

### 3. 配置小程序baseUrl
编辑 `2-小程序代码/app.js`，修改 baseUrl：
- **本机测试**: `http://127.0.0.1:5000`
- **手机真机调试**: `http://你的电脑IP:5000` (通过ipconfig查看)

## 🐛 已知问题与注意事项

### API接口差异
**问题**: 小程序API字段与后端不完全匹配

**临时解决方案**: 需要后端适配或修改小程序代码

#### 创建记录接口不匹配
**后端期望** (`/api/patrol` POST):
```javascript
{
  segment_id: int,        // 路段ID（必填）
  issue_type_id: int,     // 问题类型ID（必填）
  description: string,    // 描述
  severity: int,          // 严重度
  latitude: float,
  longitude: float,
  photo: File[]          // FormData
}
```

**小程序当前发送**:
```javascript
{
  location_desc: string,  // ❌ 字段不匹配
  problem_desc: string,   // ❌ 字段不匹配
  problem_type: string,   // ❌ 类型不匹配（string vs int）
  severity: int,
  latitude: float,
  longitude: float,
  photo_urls: string[]    // ❌ 字段不匹配
}
```

### 修复建议
**方案1: 修改小程序代码**（推荐，快速）
1. 将 `problem_type` 改为枚举ID映射
2. 将 `location_desc` + `problem_desc` 合并为 `description`
3. 添加 `segment_id` 固定值（如 1）
4. 改用FormData上传照片

**方案2: 修改后端接口**（彻底，需改数据库）
1. 在 `/api/patrol` 添加适配层
2. 支持 `location_desc` 和 `segment_id` 两种模式

## 🔧 调试技巧

### 查看请求日志
1. 微信开发者工具 → Console 面板
2. 查看 `[REQUEST]` 和 `[RESPONSE]` 日志
3. Network 面板查看详细请求

### 查看后端日志
```bash
# 后端命令行窗口会显示所有API请求
[INFO] POST /api/patrol - 200 OK
[DEBUG] 收到提交: segment_id=1, issue_type_id=1...
```

### 常见错误
1. **401 Unauthorized**: Token失效，重新登录
2. **404 Not Found**: 检查baseUrl配置
3. **422 Validation Error**: 字段格式错误，查看详细错误信息
4. **500 Server Error**: 后端异常，查看后端日志
