# 公路巡查系统 - 小程序端

## 📱 项目概述
基于微信小程序的公路巡查数据采集系统，采用深色玻璃拟态主题，支持巡查员和管理员双角色。

## 🚀 快速开始

### 1. 配置后端地址
编辑 `app.js`，修改 `baseUrl`：
```javascript
globalData: {
  // 本机开发
  baseUrl: 'http://127.0.0.1:5000',
  // 真机测试（改为开发机局域网IP）
  // baseUrl: 'http://192.168.1.100:5000'
}
```

### 2. 微信开发者工具
1. 下载并安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 使用微信扫码登录
3. 导入项目：选择 `2-小程序代码` 文件夹
4. AppID：选择"测试号"或输入自己的AppID

### 3. 开发设置（含代码质量）
在开发者工具中：
- **详情 → 本地设置**
  - ✅ 不校验合法域名
  - ✅ 不校验TLS版本
- **调试器 → Network**：查看API请求
- **代码质量**：在 `app.json` 顶层启用按需注入
  ```json
  {
    "lazyCodeLoading": "requiredComponents"
  }
  ```

### 4. 真机调试
1. 确保手机和开发机在同一局域网
2. 修改 `baseUrl` 为开发机IP
3. 启动后端服务器（监听0.0.0.0）
4. 点击工具栏"真机调试"，扫码测试

## 🔌 后端API对接

### 需要的接口
```
POST   /api/user/login        # 用户登录
GET    /api/patrol             # 获取记录列表
POST   /api/patrol             # 创建记录
GET    /api/patrol/{id}        # 获取记录详情
GET    /api/patrol/stats       # 获取统计数据
POST   /api/photo/upload       # 上传照片
```

### 请求格式
```javascript
// 创建记录示例
POST /api/patrol
{
  "location_desc": "国道G107 36公里处",
  "problem_desc": "路面有坑洼，深约10cm",
  "problem_type": "road_damage",
  "severity": 3,
  "latitude": 23.123456,
  "longitude": 113.234567,
  "photo_urls": ["/photos/abc123.jpg"]
}
```

## 💡 开发建议

### 样式规范
- 使用全局CSS变量（`var(--text-primary)`）
- 遵循深色主题配色
- 圆角统一使用16rpx/24rpx
- 间距使用8rpx的倍数

### 代码规范
- 使用async/await处理异步
- 统一使用utils工具函数
- 接口调用使用request封装
- 错误统一Toast提示

### 性能优化
- 列表分页加载
- 图片懒加载
- 防抖/节流（utils.debounce）
- 缓存常用数据
