# 文档导航与照片说明

## 照片存储与访问
- 存储目录：后端统一使用 [1-后端代码/photos](../1-后端代码/photos)
- 访问 URL：`http://<服务器IP>:5000/photos/<文件名>.jpg`
- 生成/上传：所有上传与测试数据生成均写入上述目录（`settings.UPLOAD_FOLDER` 已标准化为后端绝对路径）。
- 启动提示：
  - 首次初始化（含建库）：`uvicorn app:app --host 127.0.0.1 --port 5000`
  - 日常运行（跳过 DB 初始化）：运行 [1-后端代码/start_server.py](../1-后端代码/start_server.py)

## 主要文档入口
- 按钮修复索引：`后端按钮修复/📖文档索引-按钮修复.md`
- 系统架构与操作指南：查看同级目录下的详细 Markdown 文档。
