**改动2：get_admin_stats() 函数**

旧函数签名（第340行）：
```python
def get_admin_stats(start_date=None, end_date=None, region=None):
```

新函数签名：
```python
def get_admin_stats(start_date=None, end_date=None, region=None, 
                   scope=None, province=None, city=None):
```

新增参数说明：
- `scope`: 'world' | 'china' | 'province' | 'city'
- `province`: 省份名称，如'浙江省'
- `city`: 城市名称，需配合province使用

新增GPS过滤逻辑：
```python
# GPS过滤：根据scope、province、city确定地理边界
if scope == 'province' and province:
    bounds = get_province_gps_bounds(province)
    if bounds:
        where_clause += f" AND ir.latitude BETWEEN {bounds['lat_min']} AND {bounds['lat_max']}"
        where_clause += f" AND ir.longitude BETWEEN {bounds['lon_min']} AND {bounds['lon_max']}"
elif scope == 'city' and province and city:
    bounds = get_city_gps_bounds(province, city)
    if bounds:
        where_clause += f" AND ir.latitude BETWEEN {bounds['lat_min']} AND {bounds['lat_max']}"
        where_clause += f" AND ir.longitude BETWEEN {bounds['lon_min']} AND {bounds['lon_max']}"
```

返回值增加作用域信息：
```python
return {
    'total_records': total,
    'status_breakdown': status_breakdown,
    'type_breakdown': type_breakdown,
    'severity_breakdown': severity_breakdown,
    'recent_7_days': recent_7_days,
    'recent_30_days': recent_30_days,
    'scope': scope or 'world',
    'region': province or city or region or 'global'
}
```

**工作原理**：
```
用户点击浙江省
  ↓
前端: fetchStats({scope: 'province', province: '浙江省'})
  ↓
后端: get_admin_stats(scope='province', province='浙江省')
  ↓
1. 获取浙江省GPS范围: bounds = {lat_min: 27.2, lat_max: 34.7, ...}
  ↓
2. 构建SQL: WHERE latitude BETWEEN 27.2 AND 34.7 
           AND longitude BETWEEN 118.2 AND 123.3
  ↓
3. 执行COUNT/GROUP BY查询
  ↓
4. 返回浙江省内的统计数据
  ↓
前端: renderCharts(stats) - 图表显示浙江省数据
```

    scope: str = Query('world', description="数据范围：world|china|province|city"),
    province: str = Query(None, description="省份名称（如'浙江省'）"),
    city: str = Query(None, description="城市名称"),
    start_date: str = Query(None, description="开始日期 YYYY-MM-DD"),

    获取统计数据
    
    示例：
    - /api/public/stats?scope=world → 全球统计
    - /api/public/stats?scope=china → 中国统计

            region=region,
            scope=scope,
            province=province,
            city=city,
            start_date=start_date,
            end_date=end_date
        )

## ⚠️ 重要注意

1. **GPS边界精确性**：
   - 省份范围是根据地理边界估算的
   - 城市范围使用100km半径（可通过expand_km参数调整）

2. **数据一致性**：
   - 生成的测试数据自动分配到各省份
   - 保证 `总记录数 = 北京 + 上海 + ... + 新疆` 

3. **性能考虑**：
   - 当前通过SQL WHERE条件过滤（每次查询都计算）
   - 未来可优化：添加province_id字段或创建索引

4. **兼容性**：
   - 保留了原有的region参数以保持向后兼容
   - 新参数scope/province/city不影响旧API调用
