## 🔧 技术架构

### 前端流程
```
用户在map.html点击省份
  ↓
触发 bindChinaClick() 或 loadProvinceMap()
  ↓
调用 fetchStats({scope:'province', province:'浙江省'})
  ↓
请求 /api/public/stats?scope=province&province=浙江省
  ↓
更新右侧图表数据
```

### 后端流程
```
GET /api/public/stats?scope=province&province=浙江省
  ↓
routes/admin.py: public_stats(scope, province, ...)
  ↓
models/tasks.py: get_admin_stats(scope='province', province='浙江省')
  ↓
models/china_regions.py: get_province_gps_bounds('浙江省')
  → 返回 {lat_min:27.2, lat_max:34.7, lon_min:118.2, lon_max:123.3}
  ↓
SQL: SELECT COUNT(*) FROM InspectionRecord 
     WHERE latitude BETWEEN 27.2 AND 34.7 
     AND longitude BETWEEN 118.2 AND 123.3
  ↓
返回统计结果 {total_records: 69, status_breakdown: {...}, ...}
```

## 🐛 常见问题

### Q: 为什么某个城市返回0条记录？
A: 城市范围是以城市中心±100km为范围。如果随机生成的数据没有恰好落在范围内，就是0条。
   - 解决：运行 `python add_hangzhou_data.py` 为该城市添加专用数据

### Q: 如何修改城市范围大小？
A: 编辑 [models/china_regions.py](models/china_regions.py) 中的 `get_city_gps_bounds()` 函数，修改 `expand_km` 参数（默认100km）

### Q: 数据没有随地图选择更新？
A: 检查浏览器控制台，确认：
   1. fetchStats 发送了正确的URL
   2. /api/public/stats 返回了200状态
   3. 返回数据的 `total_records` 字段不为0

### Q: 想添加新的省份/城市？
A: 编辑 [models/china_regions.py](models/china_regions.py) 的 `CHINA_PROVINCES_GPS` 字典，按格式添加新数据
