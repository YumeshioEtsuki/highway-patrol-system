## v1.2.0 - 性能与安全全面优化（2025-12-23）

### ✨ 新功能
- **骨架屏加载动画**：统计卡片、图表、表格加载时显示 shimmer 占位符
- **审计日志导出**：支持将管理员操作日志导出为 CSV 格式
- **数据库连接池**：可选的 MySQL 连接池支持（可配置池大小）

### ⚡ 性能优化
- **数据库索引脚本**：添加关键列索引，查询速度提升 10-100 倍
- **统计数据缓存**：支持 Redis 或内存缓存，默认 TTL 600s
- **请求耗时日志**：自动记录所有 HTTP 响应时间

### 🔐 安全加固
- **速率限制**：
  - POST /api/user/login → 5 次/分钟
  - POST /api/admin/reinit → 1 次/分钟
  - POST /api/admin/generate → 3 次/分钟
  - POST /api/admin/clean-test-data → 2 次/分钟
- **审计日志追踪**：所有敏感操作被记录，支持导出审查
- **环境变量规范化**：完善 `.env.example`，配置清晰可控

- 项目 README 更新（最新优化亮点、文档导航）

## v1.1.2 - GPS地理过滤功能（2025-01-15）

### ✨ 新功能
- **GPS地理边界过滤**：支持按全球→中国→省份→城市分层过滤
- **34省份GPS数据库**：`models/china_regions.py` 包含所有省份坐标范围
- **多城市支持**：每个省份预配置 3+ 个城市中心点

### 🔧 改进
- 测试数据生成现在按省份分布，确保地理真实性
- 数据统计 API 支持新参数：`scope`、`province`、`city`
- 自动化测试脚本验证所有地区数据

## 🔧 核心技术栈

### 后端
- **框架**：FastAPI 0.100+
- **数据库**：MySQL 5.7 / 8.0
- **认证**：JWT + Argon2 密码哈希
- **缓存**：Redis（可选）或内存缓存
- **日志**：自定义 logger，支持文件滚动

### 前端
- **HTML5 + CSS3 + JavaScript**
- **图表库**：Chart.js、ECharts
- **地图**：开源地图库
- **样式**：Glassmorphism 设计

### 小程序
- **语言**：TypeScript/WXSS
- **API 通信**：HTTP/WSS
- **存储**：LocalStorage
