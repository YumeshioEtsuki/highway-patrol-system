## 🎯 新增表结构

### AuditLog（审计日志表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INT PRIMARY KEY AUTO_INCREMENT | 审计记录ID |
| user_id | INT | 操作用户ID（外键→User） |
| username | VARCHAR(50) | 用户名（冗余字段） |
| action | VARCHAR(100) | 操作类型（登录/新增/修改/删除） |
| resource | VARCHAR(255) | 操作资源（记录ID/用户ID等） |
| details | TEXT | 操作详情JSON |
| ip_address | VARCHAR(45) | 操作IP地址 |
| timestamp | DATETIME | 操作时间（自动记录） |

**外键约束：**
```sql
FOREIGN KEY (user_id) REFERENCES User(user_id) ON DELETE SET NULL
```

**索引：**
- `idx_user_id` - 用户维度查询
- `idx_action` - 操作类型筛选
- `idx_timestamp` - 时间范围查询

## 🔧 代码修改清单

### schema.py
```python
CREATE_TABLES_SQL = [
    # ... 原有6张表 ...
    """
    CREATE TABLE AuditLog (
        id INT PRIMARY KEY AUTO_INCREMENT,
        user_id INT,
        username VARCHAR(50),
        action VARCHAR(100) NOT NULL COMMENT '操作类型',
        resource VARCHAR(255) COMMENT '操作资源',
        details TEXT COMMENT '操作详情JSON',
        ip_address VARCHAR(45) COMMENT '操作IP地址',
        timestamp DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '操作时间',
        FOREIGN KEY (user_id) REFERENCES User(user_id) ON DELETE SET NULL,
        INDEX idx_user_id (user_id),
        INDEX idx_action (action),
        INDEX idx_timestamp (timestamp)
    ) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='审计日志表';
    """  # ← 新增
]
```
