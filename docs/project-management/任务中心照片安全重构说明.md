# 任务中心照片安全重构文档

## 📋 重构概述

本次重构将任务中心的照片处理方式从**手动输入文件路径**改为**安全的照片ID选择机制**，大幅提升系统安全性和用户体验。

---

## 🎯 核心改进

### 1. 安全性提升
- ✅ 用户无法直接访问服务器文件系统路径
- ✅ 所有照片通过唯一 `photo_id` 标识
- ✅ 后端内部进行安全的路径映射
- ✅ 防止路径遍历攻击和任意文件访问

### 2. 用户体验优化
- ✅ 从下拉列表选择已上传照片
- ✅ 支持直接上传新照片
- ✅ 自动刷新照片列表
- ✅ 显示照片文件名和上传时间

### 任务路由修改

所有照片相关任务的请求模型已从 `photo_path: str` 改为 `photo_id: str`：

| 任务类型 | 旧参数 | 新参数 | 路由 |
|---------|--------|--------|------|
| 压缩照片 | `photo_path` | `photo_id` | `/api/tasks/photo/compress` |
| 生成缩略图 | `photo_path` | `photo_id` | `/api/tasks/photo/thumbnail` |
| 批量处理 | `photo_paths[]` | `photo_ids[]` | `/api/tasks/photo/batch` |
| AI质量检测 | `photo_path` | `photo_id` | `/api/tasks/ai/check-quality` |

**安全验证**：
- 如果请求包含 `photo_path` 参数，后端将返回 `400 Bad Request`
- 所有任务必须使用 `photo_id`

**路径映射函数**：
```python
def get_photo_path_from_id(photo_id: str) -> str:
    """
    安全的 photo_id 到文件路径映射
    
    注意：实际生产环境应从数据库查询
    """
    # TODO: 从数据库查询真实路径
    # SELECT file_path FROM patrol_photos WHERE photo_id = ?
    
    # 临时实现：文件系统查找
    upload_folder = settings.UPLOAD_FOLDER
    for ext in ['jpg', 'jpeg', 'png', 'gif', 'webp']:
        pattern = os.path.join(upload_folder, '**', f"{photo_id}.{ext}")
        matches = glob.glob(pattern, recursive=True)
        if matches:
            return matches[0]
    
    raise FileNotFoundError(f"照片不存在: photo_id={photo_id}")
```

```javascript
// 1. 页面加载时获取照片列表
async function loadUserPhotos() {
    const response = await fetch('/api/photos/user', {
        headers: { 'Authorization': `Bearer ${token}` }
    });
    const data = await response.json();
    userPhotos = data.data;
    populatePhotoSelects();  // 填充所有下拉框
}

// 2. 上传新照片
async function uploadPhotoFile(fileInput) {
    const formData = new FormData();
    formData.append('file', fileInput.files[0]);
    
    const response = await fetch('/api/photos/upload', {
        method: 'POST',
        headers: { 'Authorization': `Bearer ${token}` },
        body: formData
    });
    
    const result = await response.json();
    return result.photo_id;  // 返回照片ID
}

// 3. 提交任务（优先使用上传的新照片）
async function submitCompress() {
    let photoId = document.getElementById('compressPhotoSelect').value;
    const uploadInput = document.getElementById('compressPhotoUpload');
    
    // 如果上传了新文件，优先使用
    if (uploadInput.files.length > 0) {
        photoId = await uploadPhotoFile(uploadInput);
    }
    
    if (!photoId) {
        return alert('请选择或上传照片');
    }
    
    // 使用 photo_id 提交任务
    submitTask('/api/tasks/photo/compress', { 
        photo_id: photoId, 
        quality: 85 
    });
}
```

```python
def get_photo_path_from_id(photo_id: str) -> str:
    from utils.utils import get_db_connection
    
    conn = get_db_connection()
    cursor = conn.cursor()
    cursor.execute("SELECT file_path FROM patrol_photos WHERE photo_id = %s", (photo_id,))
    result = cursor.fetchone()
    cursor.close()
    conn.close()
    
    if not result:
        raise FileNotFoundError(f"照片不存在: {photo_id}")
    
    return result[0]
```
