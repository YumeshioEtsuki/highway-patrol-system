## 🐛 潜在问题

### 1. Token Key 不一致
**问题**：monitor-dashboard.js 使用 `localStorage.getItem('token')`，而其他页面使用 `'access_token'`。

**解决方案**：统一修改为 `'access_token'`：

```javascript
// monitor-dashboard.js 第 10 行
authToken = localStorage.getItem('access_token');  // 改为 access_token
```

### 2. 数据库表依赖
监控功能依赖以下数据库表：
- `slow_query_logs` - 慢查询日志
- `performance_metrics` - 性能指标历史
- `optimization_recommendations` - 优化建议

**检查表是否存在**：
```sql
SHOW TABLES LIKE '%slow_query%';
SHOW TABLES LIKE '%performance_metrics%';
SHOW TABLES LIKE '%optimization%';
```

如果表不存在，功能可能无法正常工作。

### 3. MetricsCollector 依赖简化
当前 MetricsCollector 依赖 `slow_query_logs` 表。如果表不存在，建议使用简化版本（已在任务中心修复中实现）。

### 3. 添加数据表检查

在 monitor_routes.py 中添加表存在性检查：
```python
def check_tables_exist():
    """检查必要的监控表是否存在"""
    from utils.utils import get_db_connection
    conn = get_db_connection()
    cursor = conn.cursor()
    
    tables = ['slow_query_logs', 'performance_metrics', 'optimization_recommendations']
    missing = []
    
    for table in tables:
        cursor.execute(f"SHOW TABLES LIKE '{table}'")
        if not cursor.fetchone():
            missing.append(table)
    
    cursor.close()
    conn.close()
    
    return missing
```
