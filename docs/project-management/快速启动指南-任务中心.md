# 快速启动指南 - 任务中心照片安全重构

## 🚀 启动步骤

### 1. 启动 Redis（如果未运行）
```powershell
# 使用 Docker
docker start redis-server

# 或直接运行 Redis
redis-server
```

### 2. 启动 FastAPI 后端
```powershell
cd "d:\MySQL Project\highway-patrol-system\1-后端代码"
python app.py
```

预期输出：
```
INFO:     Uvicorn running on http://0.0.0.0:8000
INFO:     Application startup complete
```

### 3. 启动 Celery Worker
```powershell
# 新开一个终端
cd "d:\MySQL Project\highway-patrol-system\1-后端代码"
celery -A celery_app worker --pool=solo -l info
```

预期输出：
```
[tasks]
  . tasks.photo_tasks.compress_photo
  . tasks.photo_tasks.generate_thumbnail
  . tasks.ai_tasks.check_photo_quality
  ...
celery@hostname ready
```

### 4. 访问任务中心
浏览器打开：http://localhost:8000/tasks.html

## ✅ 功能验证

### 测试照片上传
1. 点击"压缩照片"按钮
2. 点击"或上传新照片"下的文件选择按钮
3. 选择一张图片（jpg/png/gif/webp）
4. 设置压缩质量（默认85）
5. 点击"提交任务"

**预期结果**：
- ✅ 显示"照片上传成功"通知
- ✅ 任务列表出现新任务
- ✅ Celery日志显示任务执行

### 测试照片选择
1. 重新打开"压缩照片"模态框
2. 下拉框中应显示刚才上传的照片
3. 选择照片后提交任务

**预期结果**：
- ✅ 无需重新上传，直接使用已有照片
- ✅ 任务成功提交

### 测试AI质量检测
1. 点击"AI质量检测"
2. 从下拉框选择照片
3. 设置检测阈值（默认0.7）
4. 提交任务

**注意**：需要 Ollama 服务运行在 localhost:11434

## ⚠️ 常见问题

### 问题1：照片列表为空
**原因**：尚未上传任何照片  
**解决**：先通过UI上传一张测试照片

### 问题2：任务提交后无响应
**原因**：Celery Worker 未启动  
**解决**：检查 Celery 进程，确保 `celery -A celery_app worker` 正在运行

### 问题3：上传照片报错"照片不存在"
**原因**：路径映射函数未找到文件  
**解决**：
1. 检查 `settings.UPLOAD_FOLDER` 配置
2. 确保照片保存成功
3. 查看FastAPI日志中的文件路径

### 问题4：AI质量检测失败
**原因**：Ollama 服务未运行  
**解决**：
```powershell
# 启动 Ollama
ollama serve

# 或跳过AI任务测试
```

### 问题5：Token过期
**症状**：请求返回 401 Unauthorized  
**解决**：重新登录获取新token

## 📊 性能基准

| 操作 | 预期时间 | 说明 |
|------|---------|------|
| 照片上传 (1MB) | < 1s | 取决于网络速度 |
| 照片列表查询 | < 100ms | 最多返回100张 |
| 任务提交 | < 200ms | 仅提交，不等待执行 |
| 照片压缩 (2MB) | 2-5s | Celery后台执行 |
| 生成缩略图 | 1-2s | Celery后台执行 |
| AI质量检测 | 10-30s | 取决于Ollama模型 |
