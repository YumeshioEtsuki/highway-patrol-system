## 🔌 API 使用示例

### 1. 获取仪表板
```bash
GET http://127.0.0.1:5000/monitor
```

### 2. 获取当前指标
```bash
curl -H "Authorization: Bearer <token>" \
  http://127.0.0.1:5000/api/admin/monitor/metrics/current

# 返回
{
  "queries_per_sec": 45.2,
  "slow_queries_per_min": 3,
  "avg_query_time_ms": 125.5,
  "cache_hit_ratio": 0.87,
  ...
}
```

### 3. 获取最慢的 5 条查询
```bash
curl -H "Authorization: Bearer <token>" \
  http://127.0.0.1:5000/api/admin/monitor/slow-queries/top?limit=5
```

### 4. 生成优化建议
```bash
curl -X POST -H "Authorization: Bearer <token>" \
  http://127.0.0.1:5000/api/admin/monitor/recommendations/generate
```

### 5. 应用优化建议
```bash
curl -X POST -H "Authorization: Bearer <token>" \
  http://127.0.0.1:5000/api/admin/monitor/recommendations/1/apply
```
