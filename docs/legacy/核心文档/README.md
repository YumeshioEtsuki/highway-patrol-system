## 核心信息速查

### 数据库
- **引擎**: MySQL 8.0+
- **初始化**: `1-后端代码/models/schema.py`
- **脚本**: `3-数据库/create_database.sql`
- **迁移**: 见 `6-开发日志/项目体检报告.md` 中的索引优化建议

### 后端 API
- **框架**: FastAPI 0.104+
- **端口**: 5000 (开发环境)
- **文档**: http://localhost:5000/docs (Swagger)
- **ReDoc**: http://localhost:5000/redoc

### 前端
- **平台**: 微信小程序
- **语言**: TypeScript + WXSS
- **测试**: 见 `2-小程序代码/真机测试指南.md`

### 环境配置
- **配置文件**: `1-后端代码/.env` (本地，不提交)
- **配置模板**: `1-后端代码/.env.example`
- **编码规范**: `.editorconfig` (多 IDE 通用)

## 贡献指南

文档由整个开发团队维护。新增文档时：

1. **放置位置**:
   - 快速开始类 → `docs/` (如 SETUP.md, DEVELOPMENT.md)
   - 诊断报告类 → `6-开发日志/` (如项目体检报告.md)
   - 详细功能类 → `4-文档/` (如 API接口文档.md)

2. **命名规范**: 英文 Markdown + 连字符 (`setup-guide.md`) 或中文清晰 (`项目体检报告.md`)

3. **格式约定**:
   - 使用 Markdown 标准格式
   - 文件顶部添加 "📚 文档中心" 链接便于导航
   - 定期检查超链接有效性

4. **更新此文件**: 新增重要文档后，更新本 README.md 的导航菜单
