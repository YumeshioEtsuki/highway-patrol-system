# 后端管理系统登出和管理员按钮修复 - 手动验证指南

## 问题概述

**原始问题**：用户使用admin账户登录后端网页系统后，patrol页面中应该显示的两个按钮（**退出登录** 和 **管理员页面**）没有出现。

**根本原因**：`patrol.html`的`handleLogin()`函数在登录成功后，没有检查用户的`role`字段来决定是否显示管理员按钮，导致用户需要刷新页面才能看到按钮。

**修复方式**：在`handleLogin()`函数中添加role检查逻辑，使登录后立即显示正确的按钮。

**修改后**：
```javascript
if (res.ok && data.access_token) {
    setTokenWithExpire(data.access_token);
    showMessage('login-message', '登录成功！');
    const user = data.user || {};
    document.getElementById('welcome-name').textContent = user.real_name || username;
    document.getElementById('auth-section').classList.add('hidden');
    document.getElementById('patrol-section').classList.remove('hidden');
    
    // 检查用户角色，如果是管理员则显示管理员按钮
    if (user.role === 'admin') {
        document.getElementById('admin-btn').style.display = 'inline-flex';
    } else {
        document.getElementById('admin-btn').style.display = 'none';
    }
    
    await loadRoadSegments();
    await loadIssueTypes();
    await loadPatrolRecords();
}
```

**改动说明**：
- 在设置welcome-name和显示patrol-section后，检查`user.role`
- 如果role === 'admin'，将admin按钮从`display:none`改为`display:inline-flex`
- 否则确保admin按钮被隐藏

## 常见问题排查

### 问题：登录后仍然看不到按钮
**可能原因**：
1. 浏览器缓存未清理
   - 解决：清除Local Storage和浏览器缓存，刷新页面
2. JavaScript出现错误
   - 解决：打开开发者工具Console，查看是否有错误信息
3. 后端服务未运行
   - 解决：确保FastAPI服务在http://localhost:5000运行

### 问题：看到admin按钮但点击后无法访问admin.html
**原因**：后端权限检查
- 这是正常的。虽然前端显示按钮，但后端会检查用户角色
- 如果token中的role不是'admin'，会被拒绝访问

### 问题：登出后刷新仍然看到登录状态
**可能原因**：
1. Token未被正确清除
   - 解决：检查logout()函数是否被执行
   - 用开发者工具验证localStorage是否为空
2. 浏览器缓存
   - 解决：完全关闭浏览器标签页，重新打开

### 问题：刷新后登录状态丢失
**原因**：这是正常的如果：
- token_expires已过期（超过24小时）
- localStorage被清除
- 浏览器进入隐私模式

**解决**：重新登录
