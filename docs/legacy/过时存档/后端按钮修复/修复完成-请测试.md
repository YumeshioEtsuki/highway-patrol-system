## 🔍 如果还是连接失败

### 在手机浏览器测试连接
用手机浏览器（微信、Safari、Chrome等）打开：
```
http://10.61.42.124:5000/docs
```

**如果能打开**：说明网络连接正常，问题可能在小程序配置
**如果打不开**：说明网络连接有问题，检查：
1. WiFi是否相同
2. 路由器是否开启了AP隔离（设备间隔离）
3. 电脑防火墙是否完全关闭了5000端口

### 查看小程序调试信息
在手机小程序界面：
1. 点击右上角"..."
2. 选择"开启调试"
3. 查看控制台的错误信息

### 查看后端日志
后端服务器控制台会显示所有请求，例如：
```
INFO:     10.61.42.124:xxxxx - "POST /api/login HTTP/1.1" 200 OK
```

如果看到来自手机IP的请求，说明连接成功！
