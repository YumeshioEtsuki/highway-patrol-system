## 📞 问题排查

遇到问题？按以下步骤：

1. **查看日志**
   ```bash
   tail -f logs/app_YYYY-MM-DD.log
   ```

2. **查阅文档**
   - [常见问题](../1-后端代码/README.md#常见问题)
   - [优化原理](../4-文档/优化原理简明指南.md)

3. **运行诊断**
   ```bash
   python test_gps_filtering.py
   ```

4. **提交反馈**
   - 详细描述问题
   - 提供错误日志
   - 说明重现步骤
