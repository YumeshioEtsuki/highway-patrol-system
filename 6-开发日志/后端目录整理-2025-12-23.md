## 如何使用

### 运行后端
```bash
cd 1-后端代码
python start_server.py
```

### 生成测试数据（搬家后的新位置）
```bash
# 杭州地区数据
python 7-测试脚本/add_hangzhou_data.py

# 重置数据库
python 7-测试脚本/reset_db.py

# GPS 功能测试
python 7-测试脚本/test_gps_filtering.py
```

### 数据库索引初始化
