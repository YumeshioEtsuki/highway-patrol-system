# 📱 小程序真机测试指南

## 🎯 测试前准备

### 1. 网络环境
确保手机和开发电脑在**同一个WiFi网络**下。

### 2. 查看电脑IP地址

#### Windows系统
打开PowerShell或命令提示符，输入：
```bash
ipconfig
```
查找"无线局域网适配器 WLAN"下的"IPv4 地址"，例如：`192.168.1.100`

#### Mac/Linux系统
打开终端，输入：
```bash
ifconfig | grep "inet "
```
查找局域网IP，通常是 `192.168.x.x` 格式

## 🔧 配置步骤

### 步骤1：修改后端地址

打开 `app.js`，修改 `baseUrl`：

```javascript
globalData: {
  userInfo: null,
  token: null,
  // 将下面的IP改为你的电脑IP
  baseUrl: 'http://192.168.1.100:5000',  // ← 修改这里
  userRole: null
},
```

**重要**：
- 开发工具测试：使用 `http://127.0.0.1:5000`
- 真机测试：使用 `http://[你的电脑IP]:5000`

### 步骤2：启动后端服务器

确保后端服务器监听所有IP（0.0.0.0），而不只是127.0.0.1。

打开 `1-后端代码/start_server.py`，确认包含：
```python
app.run(
    host='0.0.0.0',  # ← 监听所有IP
    port=5000,
    debug=True
)
```

启动后端：
```bash
cd "d:\MySQL Project\highway-patrol-system\1-后端代码"
python start_server.py
```

看到以下信息说明启动成功：
```
 * Running on http://0.0.0.0:5000
```

### 步骤3：检查防火墙

#### Windows防火墙
1. 按 `Win + R`，输入 `firewall.cpl`
2. 点击"允许应用通过Windows防火墙"
3. 找到"Python"或你的开发工具，确保勾选"专用"和"公用"

或直接在PowerShell中运行（管理员权限）：
```powershell
# 允许5000端口入站
New-NetFirewallRule -DisplayName "Flask Server" -Direction Inbound -LocalPort 5000 -Protocol TCP -Action Allow
```

### 步骤4：扫码预览

1. 在微信开发者工具中，点击工具栏的"预览"按钮
2. 用手机微信扫描生成的二维码
3. 小程序会在手机上打开

## ❗ 常见问题

### 1. 扫码后提示"网络连接失败"

**原因**：手机无法访问电脑的5000端口

**解决方法**：
1. 检查手机和电脑是否在同一WiFi
2. 确认 `app.js` 中的IP地址正确
3. 测试电脑防火墙是否放行5000端口：
   ```bash
   # 在手机浏览器中访问
   http://[你的电脑IP]:5000/api/health
   ```
   如果能看到JSON响应，说明网络连接正常

4. 重启后端服务器
5. 检查路由器是否开启了AP隔离（禁止设备间通信）

### 2. 登录后提示"认证失败"

**原因**：Token验证失败或数据库问题

**解决方法**：
1. 点击登录页的"清除缓存并重登"
2. 查看后端控制台的错误日志
3. 检查数据库连接是否正常

### 3. GPS定位失败

**原因**：室内GPS信号弱或未授权

**解决方法**：
1. 到室外或窗户附近测试
2. 在手机微信小程序设置中允许位置权限
3. 重启小程序

### 4. 照片上传失败

**原因**：网络不稳定或文件过大

**解决方法**：
1. 检查网络连接
2. 尝试上传较小的照片
3. 查看后端日志确认上传路径存在

### 5. 照片显示不出来

**原因**：照片URL路径错误

**解决方法**：
1. 确认后端 `photos/` 目录存在
2. 检查照片文件是否成功上传
3. 查看控制台的照片URL是否正确

## 🐛 调试技巧

### 开启调试模式
在手机小程序界面，点击右上角"..."菜单，选择"开启调试"，可以看到控制台日志。

### 查看网络请求
在开发者工具的"调试器 → Network"面板，可以查看所有API请求和响应。

### 查看后端日志
后端控制台会打印所有请求日志，包括：
```
[INFO] GET /api/patrol?status_filter=all
[DEBUG] 用户认证: user_id=1
[ERROR] 数据库错误: ...
```

### 测试API连接
在手机浏览器中直接访问：
```
http://[你的电脑IP]:5000/api/health
```
应该返回：
```json
{
  "status": "ok",
  "message": "Server is running"
}
```

## 📌 注意事项

1. **每次修改代码后**，需要重新点击"预览"生成新的二维码
2. **修改 baseUrl 后**，需要关闭并重新扫码
3. **真机测试完成后**，记得将 `baseUrl` 改回 `127.0.0.1:5000`，避免影响开发工具调试
4. **GPS定位**在室内可能不准确，建议到室外测试
5. **照片上传**时确保网络稳定，避免上传大文件
